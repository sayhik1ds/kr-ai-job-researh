# 직무 유형별 프로파일

같은 사실 저장소에서 공고 유형에 맞게 항목 순서와 강조를 바꾼다. 회사마다 문서를 새로 쓰지 않는다. `/apply` 2단계가 여기서 프로파일을 고른다.

프로파일은 `01-candidate-profile.md`의 **태그**로 항목을 고른다. 항목 본문은 바꾸지 않는다. 순서, 포함 여부, 강조 문장만 바꾼다.

### 통합형
- **대상 공고:** 프로파일 하나로 분류하기 어려운 공고. 여러 회사에 같은 문서를 낼 때
- **경력 순서:** 프로필 원래 순서
- **축소·제외:** 없음

## 축소와 제외의 뜻

- **축소**: 포트폴리오에 케이스로 넣되 행동 불릿을 2~3개로 줄이고 상세 수치를 뺀다. 이력서에는 한 줄만 남긴다
- **제외**: 포트폴리오 케이스에서 뺀다. 이력서에는 스택 줄 없이 프로젝트 이름과 한 줄 설명만 남긴다
- 포트폴리오는 케이스 4~6개다. 프로파일의 경력 순서가 3개면 "축소" 태그의 프로젝트를 축소본 케이스로 넣어 4개를 채운다. "제외" 태그는 채우는 데 쓰지 않는다

## 회사별 조정

프로파일을 고른 뒤 회사에 맞춰 바꾸는 것은 아래 둘뿐이다.

1. 포트폴리오 케이스 순서
2. 한 줄 소개에서 앞세울 프로젝트

공고가 요구하는 항목(경력 연차, 희망 근무지, 희망 연봉)은 이력서 상단에 추가한다. 그 외 항목을 새로 쓰지 않는다.

## 기록

`/apply`가 프로파일과 조정 내용을 `applications/<회사>_<포지션>/README.md`에 남긴다. 형식:

| 항목 | 값 |
|---|---|
| 프로파일 | AI 개발형 |
| 케이스 순서 | A → B → C |
| 축소·제외 | 결제 상세, 사주 계산 상세 |
| 추가 항목 | 경력 연차, 희망 근무지 |
| 격차 | Kafka 운영 경험 없음 |
